# 部署手册

这份手册是本地 RAG 知识库项目的部署说明，用来验证「入库 → 检索 → 带引用问答」整条链路。

## 环境要求

生产环境必须设置 DATABASE_URL 和 REDIS_URL 两个环境变量，缺任何一个服务都起不来。

硬件方面，最低配置是 4 核 CPU + 16GB 内存。低于 16GB 内存的机器在高峰期会因为
模型常驻 + 向量检索一起吃内存而出现 OOM。

操作系统推荐 macOS 或 Ubuntu 22.04 以上。Windows 建议用 WSL2，
因为 Ollama 在原生 Windows 上的 GPU 加速支持还不完整。

## 安装

```bash
# 1. 装推理后端
brew install ollama
brew services start ollama

# 2. 装后端依赖
cd server && uv sync

# 3. 拉生成模型（2.5GB）
ollama pull qwen3:4b
```

依赖装完一定要跑一次自检：

```bash
uv run python -m app.eval.run --k 5
```

## 环境变量

| 变量 | 是否必填 | 默认值 | 说明 |
|---|---|---|---|
| DATABASE_URL | 是 | 无 | 主库连接串，格式 postgres://user:pass@host:5432/db |
| REDIS_URL | 是 | 无 | 缓存连接串，格式 redis://host:6379/0 |
| OLLAMA_HOST | 否 | http://127.0.0.1:11434 | 推理后端地址 |
| OLLAMA_CHAT_MODEL | 否 | qwen3:4b | 生成模型名 |
| EMBED_MODEL | 否 | Qwen/Qwen3-Embedding-0.6B-Q | 向量化模型，输出 1024 维 |
| RERANK_ENABLED | 否 | true | 关掉重排可以省 1.1GB 磁盘和一次模型加载 |
| RETRIEVE_TOP_N | 否 | 50 | 召回阶段取多少条进融合 |
| RRF_K | 否 | 60 | RRF 融合常数，业界通用值 |
| RERANK_TOP_K | 否 | 5 | 重排后送进上下文多少块 |
| CHUNK_TARGET_CHARS | 否 | 500 | 分块目标字数 |

## 启动

```bash
# 后端
cd server
uv run uvicorn app.main:app --reload --port 8000

# 前端
cd web
npm run dev
```

后端起来之后先访问 http://localhost:8000/api/health 确认 Ollama 是 ok 状态。
前端默认在 http://localhost:5173，代理规则写在 web/vite.config.ts 里。

## 常见问题

### 服务启动报 Connection refused

先确认 Redis 进程是否还在：`redis-cli ping`，正常会回 PONG。
如果 Redis 正常但仍然报错，多半是 REDIS_URL 写错了，注意不要带多余的空格或换行。

### 检索召回的结果完全不相关

多半是中文没分词。BM25 索引必须用 jieba 切词，
用空格切中文的话整句会变成一个 term，召回基本等于随机。
另外确认用的是自己写的 BM25 索引，不要用 LanceDB 内置的 FTS（那是英文分词器）。

### 答案里没有引用编号

提示词里必须强制要求标注 [n]，并且参考资料每块前面要有编号。
检查 rag/prompt.py 里的 SYSTEM_PROMPT 和 build_context。

### Ollama 冷启动很慢

第一个请求要 3 到 10 秒，这是模型加载的固定开销。
用 `ollama ps` 看模型是否常驻，keep_alive 设成 5m 就能避免每次重来。

## 磁盘占用

| 组件 | 磁盘 | 常驻内存 |
|---|---|---|
| qwen3:4b | 2.5GB | 约 4GB |
| Qwen/Qwen3-Embedding-0.6B-Q | 约 1.1GB | 约 0.7GB |
| bge-reranker-v2-m3-int8 | 约 0.57GB | 约 0.3GB |
| Python 依赖 | 约 1GB | 约 0.3GB |
| 向量库与索引 | 随文档量增长 | 约 0.2GB |

磁盘紧张时优先关掉重排：RERANK_ENABLED=false 能省下 1.1GB，
代价是检索质量下降一些（具体多少要跑评测集量化，不要凭感觉）。
